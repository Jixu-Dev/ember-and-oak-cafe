## ☕ Overview

**Ember & Oak Café** is a cinematic, scroll-driven website for an artisanal coffee roastery. Featuring **GSAP-powered parallax animations**, a warm amber-toned design palette, and a full-stack architecture with a Node.js backend for contact form handling. Every scroll tells a story — from bean origin to your cup.

---

## ✨ Features

- 🎬 **Cinematic Scroll Animations** — GSAP ScrollTrigger with parallax storytelling
- ☕ **Warm Artisanal Aesthetic** — Amber, cream, and espresso color palette
- 🖼️ **Full-Bleed Hero Sections** — Immersive visual experiences on every fold
- 📧 **Contact Form Backend** — Node.js + Express server for form submissions
- 📱 **Responsive Design** — Beautiful on mobile, tablet, and widescreen
- ⚡ **Blazing Fast** — Vite-powered with optimized asset loading

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Jixu-Dev/ember-and-oak-cafe.git
cd ember-and-oak-cafe

# Install dependencies
npm install

# Start both frontend & backend
npm start

# Or run frontend only
npm run dev

# Or run backend only
npm run server
```
